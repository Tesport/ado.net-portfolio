# Дисциплина "Технология доступа к базам данных ADO.NET"
Репозиторий предназначен для хранения всех материалов, связанных с дисциплиной, включая ДЗ, практику и теоритические материалы.

## Описание дисциплины
Изучение данной дисциплины направлено на освоение навыков работы с СУБД при помощи технологии доступа ADO.NET 

## Навигация по работам

| Папка | Содержимое |
| :--- | :--- |
| **homeworks** | Домашние задания по дисциплине. Состоит из самого выполненного задания, images и README файла, кратко объясняющего суть задания и изучаемой темы. |
| **summaries** | Теоретические материалы лекций. |
| **lecture's materials** | Материалы, предоставленные преподавателем в ходе изучения дисциплины. |
| **practice** | Практические работы по основным темам курса, выполняемые на занятиях. Состоит из самого выполненного задания в md формате, images и README файла, кратко объясняющего суть задания и изучаемой темы. |
